Paperbook

Tus documentos, anotados a mano, en todos tus dispositivos

Guarda PDF y páginas web, escribe encima con lápiz o dedo, busca dentro del texto y sincroniza con Google Drive. Elige tu sistema para descargar la app.

Android

Descargar APK Paperbook-Android.apk · 0,4 MB
  1. Descarga el archivo en la tablet o el teléfono y ábrelo.
  2. Si Android lo pide, permite «instalar apps desconocidas» para tu navegador o gestor de archivos.
  3. Abre Paperbook con conexión la primera vez. Después funciona sin conexión.

La app de Android abre la versión web publicada a pantalla completa con Chrome. Si esa dirección aún no está activa, la app mostrará un error hasta que se publique.

Windows

Descargar instalador Paperbook-Setup-Windows.exe · 79 MB
Versión portátil Paperbook-Portable-Windows.exe · 79 MB
  1. Ejecuta el archivo descargado.
  2. Como no está firmado, Windows mostrará un aviso azul de SmartScreen: pulsa «Más información» y luego «Ejecutar de todas formas».
  3. El instalador crea el acceso directo. La versión portátil se abre sin instalar nada.

Linux

Descargar AppImage Paperbook-linux-x86_64.AppImage · 105 MB
Paquete .deb Paperbook-linux-amd64.deb · 73 MB
  1. AppImage: dale permiso de ejecución con chmod +x Paperbook-linux-x86_64.AppImage y ábrelo con doble clic.
  2. Debian o Ubuntu: instala el paquete con sudo apt install ./Paperbook-linux-amd64.deb.

iPad, iPhone y Mac

  1. Abre la versión web en Safari.
  2. Toca Compartir y elige «Añadir a pantalla de inicio» (en Mac: Archivo → «Añadir al Dock»).

¿Primera vez? Lee la guía de uso: cómo anotar, buscar y sincronizar tus dispositivos con un código.

Las apps de Windows y Linux llevan todo dentro y funcionan sin conexión.

Los instaladores se generan automáticamente con cada cambio. Ver todos los archivos.
